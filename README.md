# 🩺 Centro Acadêmico EERP - USP RP

Site oficial do Centro Acadêmico da Escola de Enfermagem de Ribeirão Preto da Universidade de São Paulo (EERP-USP). 

O objetivo deste projeto é centralizar informações úteis para os estudantes, facilitar o acesso a avisos importantes e disponibilizar documentos oficiais do CA, como atas de reuniões e estatutos.

---

## 🚀 Funcionalidades

* **Sobre o CA:** Apresentação institucional e o papel do centro acadêmico.
* **Avisos Úteis:** Mural rápido com horários de funcionamento, assembleias e prazos importantes.
* **Repositório de Atas e Documentos:** Lista de PDFs com atas de reuniões e estatutos organizados.
* **Busca Dinâmica:** Campo de pesquisa instantânea para filtrar atas e documentos por ano ou palavra-chave via JavaScript.
* **Design Responsivo:** Adaptado para celulares, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias web padrão, sem a necessidade de frameworks complexos ou ferramentas de build avançadas:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, variáveis de cores e layout responsivo.
* **JavaScript (Vanilla):** Funcionalidade de filtro de pesquisa em tempo real.
